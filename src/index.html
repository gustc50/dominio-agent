Olá! Eu sou o seu assistente contábil. Na aba Configurações, informe uma chave de IA (Claude ou OpenRouter) e conecte-se ao Onvio. Depois disso posso enviar XMLs de documentos fiscais ao Domínio e consultar o status de processamento dos lotes.

Configurações

Configure o acesso ao Domínio e ao provedor de IA que irá controlar o assistente.

Provedor de IA

Onvio / Domínio (Thomson Reuters)

A API do Onvio usa OAuth 2.0: ao clicar em conectar, abre-se a tela de login da Thomson Reuters. Depois de autorizar, o app guarda o token de acesso e o refresh token para renovar a sessão sozinho. As credenciais (Client ID, Client Secret e a Callback URL registrada) são liberadas pela equipe da API Onvio BR mediante solicitação.

Ações disponíveis para o assistente

  • Enviar XML de documento fiscal (NF-e, NFC-e, CT-e, CF-e) para o Domínio
  • Consultar o status de processamento de um lote enviado
  • Gerar arquivo de lançamentos contábeis no leiaute do Domínio
  • Ler um arquivo de lançamentos exportado do Domínio

As duas primeiras usam a API do Onvio. As duas últimas trabalham com o arquivo posicional do Domínio: o assistente gera o arquivo, mas a importação continua sendo feita por você dentro do Domínio. Obrigações fiscais e prazos não possuem caminho de integração disponível.
